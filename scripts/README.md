# scripts/

Utility and automation scripts for the CrossAngle project.

| Subfolder | Purpose |
|-----------|---------|
| uild/  | Build pipeline helpers (progressive enhancement, pipeline verification) |
| checks/ | Page health checks, test runners, and smoke tests |
| debug/  | Playwright debugging, transcript dumps, log fetchers |
| dev/    | One-off development utilities, migration helpers, refactor scripts |
| db/     | Database scripts — SQL inserts, schema, migration runners |

> These scripts are development/ops utilities. They are **not** part of the production bundle.
