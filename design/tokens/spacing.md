# Spacing & Material Tokens

|:------|:------|:------------|
| `--pause-vertical` | `20vh` to `30vh` | Load-bearing empty negative space between stories |
| `--nav-height` | `64px` to `72px` (max `80px`) | Single-line desktop navigation |
| `--border-hairline` | `1px solid rgba(0, 0, 0, 0.10)` | Structural material joint dividers |
| `--grain-opacity` | `0.02` | Ambient texture overlay across canvas |
| `--radius-surface` | `0px` | Sharp architectural framing |
| `--radius-interactive`| `2px` | Subtle tactile button softening |
| `--touch-min` | `44px` | Minimum mobile interactive hit target |
