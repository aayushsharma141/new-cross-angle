# Typography Tokens

| Token / Scale | Value | Application |
|:--------------|:------|:------------|
| `--font-display` | `Cormorant Garamond, serif` | Headlines, narrative serif statements |
| `--font-body` | `Instrument Sans, Inter, sans-serif` | Body paragraphs, metadata, tables |
| `--tracking-display` | `-0.02em` to `-0.04em` | Display titles (carved stone tight kerning) |
| `--tracking-body` | `0em` | Neutral reading flow |
| `--tracking-kicker` | `0.15em` to `0.20em` | Uppercase chiseled stone inscriptions |
| `--measure-body` | `65ch` (max-width) | Optimal reading column width |
| `--measure-display`| `18ch` to `24ch` | Standard headline line length target |
