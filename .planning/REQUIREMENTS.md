# Requirements: v4.0 Discovery & Estimator Operating System

## User Stories

### Discovery Configuration (DISC-CONFIG)
- [ ] **DISC-CONFIG-01**: As an administrator, I want to edit questions, visual prompts, and archetype metadata in a dedicated CMS panel, so that I can update the Discovery quiz without developer intervention.
- [ ] **DISC-CONFIG-02**: As an administrator, I want to associate specific DAM assets (hero, moodboard, lifestyle) with archetypes, so that the visual styling matches the latest campaigns.

### Estimator Configuration (EST-CONFIG)
- [ ] **EST-CONFIG-01**: As an administrator, I want to configure property types, design packages, addon options, and base pricing coefficients, so that the estimator reflects accurate market rates.
- [ ] **EST-CONFIG-02**: As an administrator, I want to manage Estimator visual assets and results templates, so that the generated estimates look professional and on-brand.

### Connected Handoff Pipeline (HANDOFF)
- [ ] **HANDOFF-01**: As a customer completing the Discovery quiz, I want my style results and preferences to automatically pre-fill the Estimator, so that I don't have to re-enter information.
- [ ] **HANDOFF-02**: As a designer, I want to view a combined lead profile showing both Discovery responses and pre-filled/completed Estimator results, so that I have a fully qualified lead context.

## Success Metrics
- 100% of Discovery quiz assets and questions configurable from the Admin dashboard.
- Estimator packages, property types, and rates fully editable in the admin panel.
- Users successfully transition from Discovery results to pre-filled Estimator with style preset.
