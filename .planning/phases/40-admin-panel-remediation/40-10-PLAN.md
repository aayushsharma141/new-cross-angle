<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> /api/auth/login and /api/auth/mfa | Credentials and one-time codes cross here |
| mfa_pending cookie -> GoTrue | AAL1 token held server-side-scoped, used only for factor calls |
| Public anon key -> GoTrue directly | Anyone can password-grant against GoTrue, bypassing this handler |
| Vercel function -> GoTrue admin API | Service key used for factor fallback |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-10-01 | Elevation of privilege | Password-only attacker obtains AAL1 session | mitigate | Task 3: no access/refresh cookie before verify; hard backstop via aal RLS + edge check (plans 40-04/40-11, activated in 40-27) because direct GoTrue grants cannot be blocked here |
| T-40-10-02 | Spoofing | Replay/theft of mfa_pending | mitigate | Task 1/2: HttpOnly, SameSite=Strict, Path=/api/auth/mfa, 10-minute TTL, cleared on success/logout/cancel; token unusable on /admin or /api/supabase (those read only access_token) |
| T-40-10-03 | Elevation of privilege | Attacker with password enrols own device | mitigate | Task 2: enrol refused with 409 when a verified factor exists; enrolment only possible while no verified factor |
| T-40-10-04 | Spoofing | TOTP brute force | mitigate | Task 2: 5 attempts / 15 min per user and 20 per IP via checkAuthRateLimit; GoTrue also rate-limits; 6-digit format validated |
| T-40-10-05 | Cross-site request forgery | mfa endpoint | mitigate | Task 2: isSameOriginRequest on every call; SameSite=Strict pending cookie |
| T-40-10-06 | Information disclosure | Tokens/codes in logs or JSON | mitigate | Tasks 1-2: no console output, tokens only in cookies, acceptance greps |
| T-40-10-07 | Denial of service (lockout) | Fail-closed on unknown state | accept | Fail-closed only when enforce_2fa is true and role/factor state is unreadable; recovery via reset-mfa (plan 40-11) and break-glass SQL (plan 40-27) |
| T-40-10-SC | Tampering | npm/pip/cargo installs | accept | No packages (cookie and supabase-js already dependencies) |
</threat_model>
