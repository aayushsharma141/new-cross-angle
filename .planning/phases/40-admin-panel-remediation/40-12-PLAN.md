| Boundary | Description |
|----------|-------------|
| Browser form -> /api/auth/mfa | One-time codes and the QR secret cross here |
| Rendered QR/secret -> shoulder surfing / screenshots | Secret shown once during enrolment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-12-01 | Information disclosure | TOTP secret persisted client-side | mitigate | Task 1: secret held only in component state; acceptance grep forbids storage APIs and console |
| T-40-12-02 | Spoofing | Duplicate enrolment calls create stray factors | mitigate | Task 1: enroll called once per mount (strict-mode guard); server deletes stale unverified factors (plan 40-10) |
| T-40-12-03 | Elevation of privilege | Client-side bypass of challenge view | accept | UI is not the control: no session cookie exists until server verify (plan 40-10); hard backstop in 40-04/40-11 |
| T-40-12-04 | Tampering | Remember-me TTL written before verify | mitigate | Task 2: TTL write only inside finishLogin after verification |
| T-40-12-05 | Information disclosure | Error text reveals whether a user has a factor | accept | The challenge/enrol branch is revealed only after a correct password |
| T-40-12-SC | Tampering | npm/pip/cargo installs | accept | No packages; QR is rendered from GoTrue's data URI, no QR library |
</threat_model>
