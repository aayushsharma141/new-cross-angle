<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Lead row (public form input) -> email HTML | name/service/message are attacker-controlled text rendered into HTML mail |
| Admin-managed lists -> outbound mail/Telegram | site_settings arrays decide who is messaged |
| Caller bearer -> edge function | Cron/trigger bearer compared to a server secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-02-01 | Tampering | renderTemplate / escapeHtml | mitigate | Task 1 escapes every substituted value and tests `<b>` injection; unknown tokens render empty rather than echoing |
| T-40-02-02 | Spoofing / abuse | parseRecipients | mitigate | Strict email regex, lower-case, dedupe, cap 10, so a corrupted jsonb value cannot fan out mail |
| T-40-02-03 | Denial of service / spam | claimThenSend | mitigate | Claim-before-send plus release-on-failure tested for double-call (Task 1) |
| T-40-02-04 | Spoofing | isServiceKeyBearer | mitigate | Constant-time compare, refuses when the configured key is empty (Task 2) |
| T-40-02-05 | Information disclosure | hardcoded chat id | mitigate | Task 1 asserts the module has no chat-id literal; chat ids come only from site_settings or an env secret |
| T-40-02-SC | Tampering | npm/pip/cargo installs | accept | No packages added |
</threat_model>
