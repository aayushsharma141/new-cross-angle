## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(var(--admin-card)) | Background, surfaces |
| Secondary (30%) | hsl(var(--admin-surface)) | Cards, sidebar, nav |
| Accent (10%) | hsl(var(--admin-primary)) | Active tabs, save buttons |
| Destructive | hsl(var(--admin-destructive)) | Destructive actions only |

Accent reserved for: Primary save buttons, active tab indicators, focus rings

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Save Configuration |
| Empty state heading | No configurations found |
| Empty state body | Add a new property type to get started. |
| Error state | Unable to save: {error message} |
| Destructive confirmation | Delete {item}: Are you sure you want to remove this configuration? |

## Workspace Layout Contract

| Element | Specification |
|---------|---------------|
| **Left Rail (Navigation)** | 280px fixed width, independent scroll |
| **Main Workspace (Editor)** | Fluid width, independent scroll |
| **Preview/Evidence Panel** | 360–400px fixed width, sticky positioning |
| **Max Content Width** | 1440px across all panels |
| **Header** | 64px fixed height, sticky top |

---

## Card Hierarchy

| Property | Specification |
|----------|---------------|
| **Border Radius** | 8px (md) for outer cards, 6px (sm) for inner items |
| **Elevation** | Flat with 1px border (`hsl(var(--admin-border))`), no shadow |
| **Padding** | 24px (lg) for forms, 16px (md) for list items |
| **Header Spacing** | 16px bottom margin below card titles |
| **Footer Actions** | Right-aligned, sticky at bottom of card if long |
| **Expanded vs Collapsed** | Smooth accordion transitions (via Radix) |

---

## Status Language

| State | Semantic Color | Usage |
|-------|----------------|-------|
| **Draft** | Gray/Muted | Unsaved or incomplete configuration |
| **Ready / Live** | Success (Green) | Active and validated estimator package |
| **Modified** | Warning (Amber) | Unsaved changes exist |
| **Archived** | Muted/Strikethrough | Legacy packages no longer offered |
| **Pending Evidence** | Info (Blue) | Missing visual thumbnail or description |

---

## Timeline / Audit Contract

| Element | Specification |
|---------|---------------|
| **Event Spacing** | 32px (xl) between major updates |
| **Timestamp Style** | 12px, Muted text, mono-spaced font |
| **Session Grouping** | Grouped by day/user |
| **Expand/Collapse** | Clickable row expands to show delta changes |
| **Icon Mapping** | Pencil (Edit), Plus (Add), Trash (Delete), ImageIcon (Media) |

---

## Workspace Behavior

| Interaction | Rule |
|-------------|------|
| **Sticky Panels** | Preview panel and Action bar (Save) must remain sticky |
| **Scrolling** | Editor and Preview scroll independently |
| **Keyboard Shortcuts** | `Cmd/Ctrl + S` to save configuration |
| **Autosave Cadence** | Local draft autosaves every 30 seconds; manual commit required |
| **Unsaved Indicator** | Amber dot on modified tabs; prompt before navigating away |

---

## Empty States

| Context | Heading | Body Copy |
|---------|---------|-----------|
| **No Configurations** | No configurations found | Add a new property type or package to get started. |
| **No Media** | No thumbnail assigned | Add a representative image to improve conversion. |
| **No Addons** | No addons configured | Offer optional upgrades to increase project value. |
| **No History** | No audit history | Changes to this configuration will appear here. |

## Responsive Layout Contract

| Breakpoint  | Behavior                                          |
| ----------- | ------------------------------------------------- |
| ≥1440px     | 3-panel workspace                                 |
| 1024–1439px | Collapse Evidence panel into right drawer         |
| 768–1023px  | Left navigation becomes collapsible               |
| <768px      | Read-only mode or unsupported for complex editing |

---

## Loading & Skeleton Contract

| State              | Rule                                              |
| ------------------ | ------------------------------------------------- |
| Initial load       | Show skeletons matching final layout              |
| Saving             | Disable primary action, show inline spinner       |
| Background refresh | Keep UI interactive with subtle loading indicator |
| Error              | Inline retry + toast, never blank screen          |
