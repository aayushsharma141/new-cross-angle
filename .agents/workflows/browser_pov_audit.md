Visitor Perception & Audit Synchronization Workflow Objective: Browser agent ke
through UI tests run karna aur user experience ke basis par reports update
karna.

Step 1: Browser Execution & Log Generation Action: Open the integrated Chrome
browser agent.

Task: UI_UX_MICROINTERACTION_TEST_PLAN.md mein diye gaye saare tests execute
karein.

Output: Is process ki saari details aur tool activities ko
browser_interaction_log.md mein save karein.

Step 2: Visitor POV Report Creation Action: Visual perception ka use karke page
analyze karein.

Task: Visitor_Experience_Report.md file banayein jisme likha ho ki ek normal
user ko page kaisa dikh raha hai (Visual hierarchy, animation quality, aur
interactions).

Artifacts: Important UI states ke screenshots capture karke report mein add
karein.

Step 3: Master Audit Report Update Action: /audit-reports folder ki saari purani
files read karein.

Task: Apne browser experience ke basis par un purani files mein naye insights
aur observations update (patch) karein.

Requirement: Actionable details add karein taaki reporting accurate ho jaye.
