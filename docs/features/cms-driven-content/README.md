# CMS-Driven Content

## What Is This?

The Content Management System (CMS) that powers all editable content on the website. Instead of needing a developer to change text or images, authorized team members can update everything through the Admin Panel.

---

## What Can Be Managed

| Content Type | Where It Appears | Admin Location |
|-------------|-----------------|----------------|
| **Blog Posts** | `/blog` page | Admin → CMS → Blogs |
| **Services** | `/services` page | Admin → CMS → Services |
| **Portfolio Projects** | `/portfolio` page | Admin → CMS → Portfolio |
| **Testimonials** | Homepage testimonials section | Admin → CMS → Testimonials |
| **Hero Section** | Homepage hero banner | Admin → CMS → Hero |
| **Gallery** | Image gallery | Admin → CMS → Gallery |
| **Team Members** | About page team section | Admin → CMS → Team |
| **Media Files** | Used across all pages | Admin → CMS → Media |

---

## Blog Management

### Creating a Blog Post
1. Go to **Admin → CMS → Blogs**
2. Click "New Post"
3. Write your article using the rich text editor
4. Add a cover image, tags, and meta description (for SEO)
5. Set status to "Published" when ready

### Blog Features
- Rich text editor with formatting, images, and links
- SEO fields (meta title, description, keywords)
- Draft/Published/Archived status
- Performance analytics (views, engagement)

---

## Services Management

### Editing a Service
1. Go to **Admin → CMS → Services**
2. Click on the service to edit
3. Update title, description, features, pricing info
4. Save — changes appear on the website immediately

---

## Media Library

A central place to upload and organize all images and files:
- **Upload**: Drag and drop images
- **Organize**: Create folders, tag files
- **Use**: Select media when editing any content
- **Optimize**: Images are automatically optimized for web delivery

---

## Content Workflow

```
Draft → Review → Published → (optionally) Archived
```

- **Draft**: Work in progress, not visible on website
- **Published**: Live on the website, visible to everyone
- **Archived**: Removed from website but kept in the system

---

## SEO Benefits

All CMS content is optimized for search engines:
- Blog posts generate indexable pages (more pages = more Google traffic)
- Service pages target specific keywords ("interior designer in [city]")
- Portfolio projects create long-tail search opportunities
- Meta descriptions and titles are editable per page

---

## Business Value

- **Independence**: Update content without waiting for a developer
- **Speed**: Changes go live instantly after publishing
- **SEO growth**: Regular blog posts improve search rankings over time
- **Consistency**: All content follows the same design system automatically
- **History**: All changes are tracked — you can always revert
